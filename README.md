# 🎲 Dice Game Simulation – Python

This is a two-player dice simulation game built in Python. Each player starts with a set amount of money and rolls a custom (or fair) die in turns. Depending on their rolls, players either lose money or take it from their opponent. The game runs multiple simulations and outputs statistics like win probability and average ending balances.

## 💡 How It Works

- Players roll dice with values 1–6.
- Rolls of **1–3** → player loses that amount.
- Rolls of **4–6** → player takes that amount (minus 3) from opponent.
- The game continues until one player runs out of money.
- You can use a fair die or input custom dice probabilities.
